How to Enable Confluence
------------------------
To use these tests, you need:
1. An Atlassian account with Confluence enabled
2. Update CONFLUENCE_USERNAME and CONFLUENCE_API_TOKEN environment variables
3. Update config/confluence_config.yaml with your Confluence URL:
   - Typically: https://your-domain.atlassian.net/wiki
   - Or: https://your-domain.atlassian.net (if using same domain)

Test Commands
-------------
cd tests/simple
set CONFLUENCE_USERNAME=your-email@example.com
set CONFLUENCE_API_TOKEN=your-api-token
python test_confluence_auth.py
python test_confluence_pages.py
